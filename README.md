# fMRI Data Analysis: Brain Network Dynamics During Creative Problem Solving

This repository focuses on the analysis and preprocessing of fMRI data to identify and isolate different task conditions. 

## Project Overview
* **Condition Tracking:** Developed scripts to map out and identify specific cognitive conditions during the experimental tasks.
* **Signal Binarization & Modeling:** Following fMRI signal preprocessing, data was binarized based on specific thresholds to apply physics-based models (such as Maximum Entropy Models) to evaluate energy landscapes and brain network dynamics across different subject groups.

## Presentation & Publication
